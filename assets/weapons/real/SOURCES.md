# Modèles 3D utilisés dans VOXEL 1.7

Les douze armes utilisent des modèles téléchargés par le bouton officiel de Sketchfab. Les fichiers GLB et BLEND ont été convertis en OBJ/MTL pour le jeu. Les textures de couleur et les normales proviennent des modèles ; les mains et les animations sont générées par le jeu.

Modifications : conversion triangulée, axes, échelle, atlas des textures d'origine, groupes de chargeur/culasse/canon/lunette et projection des icônes. Le chargeur séparé du fichier AW50 a été replacé sur le fusil. Les trois optiques utilisent la géométrie téléchargée des lunettes L96A1, M200 et AW50. Tundra désigne ici le modèle L96A1/Arctic Warfare de ruslanzod. Le MP5K compact de TastyTony remplace le VPO 136.

Le modèle AW50 d'Irma1986 est publié sous [Sketchfab Free Standard](https://sketchfab.com/licenses), avec des restrictions sur la redistribution du modèle isolé. Ses fichiers OBJ, MTL, atlas et icône restent dans le dossier de travail privé ; l'archive Windows contient leur rendu intégré au jeu, sans les fichiers de modèle séparés. Les anciennes armes Quaternius et les essais du dossier `arsenal` ne sont plus affichés par le jeu 1.7. Deux anciens OBJ restent utilisés uniquement par les tests de compatibilité du lecteur. Leur provenance CC0 est conservée dans `../SOURCES.json`.
